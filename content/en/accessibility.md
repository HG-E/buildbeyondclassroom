# Built to be usable by everyone.

BBC aims for this website to meet the Web Content Accessibility Guidelines (WCAG) 2.2 at level AA. This page says what is built in, what is checked, and how to tell us about a barrier.

## What we build in

{checks}
- Clear headings and page regions, so screen readers can move around.
- A "skip to content" link at the top of every page.
- Everything works with a keyboard, with a visible mark showing where you are.
- Text that can be enlarged to 200% without losing content.
- Colour contrast that meets AA, with colour never the only way to show meaning.
- Plain language and short sentences.
- Pages that work with JavaScript turned off, and that are small enough to load on a weak connection.
- A print version of every page.
- Light and dark colour schemes that follow your device settings, and a button to switch between them.
- Typefaces chosen for legibility, served from this site.

## How we check

Every change to this website runs automatic checks on page structure, headings, links, text alternatives, colour contrast and file sizes. Checks by hand with a keyboard and a screen reader, and with an outside accessibility tester, have not been done yet. If you meet a barrier, please tell us.

## Languages

The site is in English for now. Text is kept separate from page design so that translations can be added.

## Tell us about a problem

If you cannot use any part of this site, or you need a page in another format, please email [{{contactEmail}}](mailto:{{contactEmail}}) and tell us what you were trying to do. We will fix it or give you the information another way.
