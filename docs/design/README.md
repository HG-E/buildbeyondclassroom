# Design reference (historical)

These two files are the approved visual design and the build prompt that were used to make the site. They are kept for reference.

- `bbc-design.html` is a single-file mock-up. **It is not the website.** It loads fonts and a script from third-party hosts, and some of its wording is out of date. Several claims in it were later corrected against the gate documents. Do not copy text from it.
- `CLAUDE-CODE-PROMPT.md` is the instruction used to build the site from that design.

The real, current site is built from `content/`, `templates/`, `static/` and `build.js`, and its wording is checked against `docs/gates/`.
