# Security

This repository holds the public website of Build Beyond Classroom (BBC). It is a static site with no accounts, no database, no forms that save data and no analytics.

## Reporting a problem

If you find a security or privacy problem in the website or in this repository, please write to **buildbeyondclassroom@gmail.com**, or use the contact page at https://www.buildbeyondclassroom.com/get-involved/.

Please:

- describe what you found and where, in plain words;
- do not include personal information, and never anything about children;
- do not test the site in ways that disrupt it for other people.

This is a volunteer-run draft project, so replies may not be quick.
